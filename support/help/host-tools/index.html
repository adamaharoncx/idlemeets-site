Host Tools

How Host Tools work

Host Tools lists the meets you manage and the actions available for each one: edit supported details, post an update, review attendees, cancel, recap, or schedule it again.

What hosts can do

  • Manage detailsEdit start time, optional end time, location, flyer output, parking guidance, ride-out notes, and cancellation details.
  • Send quick updatesUse fixed templates for reminders, parking notes, ride-out reminders, and location check-ins.
  • Review contextSee attendee context, Needs attention items, Next up, and past-meet recaps.
  • Host againReuse a past setup while choosing a fresh future date before posting.

What to expect

Host Tools actions are for the signed-in account that manages the Idle post. Public host credit does not automatically transfer editing, cancellation, or Host Tools permissions.

Troubleshooting

  • Host Tools missingConfirm you are signed into the account that posted or manages the meet.
  • End time will not saveConfirm the end time is after the start time, or remove the end time if the meet should only show a start time.
  • Update reached fewer peopleSome attendees may not be marked Going or Interested, or may not allow host updates.
  • Host again shows old detailsChoose a fresh future date before posting the new meet.

Contact support

Email support@idlemeets.com with the meet title, host account, what you tapped, and the exact message shown.
