Parking

How parking plans work

Parking plans help hosts show attendees where to stage, where not to park, and what to know before arriving.

Screenshots show sample content from the Idle test drive in a prerelease build, version 1.3.0 (1), using Dark appearance and Alpine White. Your app may look different. Learn about the test drive.

Start with a parking image

  1. Create a meet or open a draft in the Host flow.
  2. Choose Add parking plan to open the Parking Plan editor.
  3. Use Add image in the Base image section to start with a lot screenshot or garage map.

The empty editor asks for an image first. Choose a clear view of the lot, then use marked areas and notes when helpful to explain where attendees should and should not park.

Check the plan before you arrive

If the host added a parking plan, review it from the meet detail page. Read the marked areas, legend, and arrival note together.

This sample distinguishes the entry, parking area, host spot, no-parking area, and overflow. The note also calls out the fire lane.

Always follow venue rules, local laws, posted signs, and the host’s current guidance. The pictured plan is Demo content, not instructions for a real venue.

For hosts

Review the meet detail page so the parking guidance is clear to attendees. For an existing meet, use the parking controls in Host Tools.

Troubleshooting

  • Plan missingThe host may not have added parking guidance yet.
  • Image unclearAsk the host for clarification or email support with the meet title.
  • Changes will not saveReopen Host Tools, check your connection, and try saving again.

Contact support

Email support@idlemeets.com with the meet title, what parking detail is missing, and a screenshot if possible.
