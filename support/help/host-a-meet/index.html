Hosting

Host a meet

A good meet page gives people the basics before they leave: where, when, the full time window if there is one, who is hosting, how visible the meet is, and what to expect when they arrive.

These screenshots use sample content in a preview version of Idle. Your app may look different. Select an image to see the full screen.

Start with the meet details

Open Host from the bottom navigation. If the chooser appears, select Start new meet. The flow has three stages: Create, Flyer, and Share.

  • TitleUse a clear name that matches the meet.
  • Date and timeCheck the start date and time. Add an optional end time for a clear start-to-end window, or use Remove end time to leave it open.
  • LocationAdd the location name and city so attendees know where they are going.

Choose visibility and rules

Choose Public for nearby discovery, or Group for a group meet. Check that you have access to the group you intend to use.

Tap common rule chips such as No revving, No burnouts, and Respect location, then review the description. Add any location-specific instructions people need.

If you are posting for someone else, review Host credit before continuing.

Save unfinished work

Use the save control before leaving the Host flow. Reopen Host and choose your meet under Unfinished drafts to continue.

The chooser labels these drafts Saved only on this iPhone. For a setup you want to reuse, save a meet template instead of relying on an unfinished draft.

Review the flyer, then the Share stage

Open Flyer and review the design in the formats you plan to use. See Edit and share meet flyers for the format and text controls.

Continue to share opens separate controls for Share flyer image, Instagram Story, Post hosted meet, and Save as template. Check the title, schedule, location, visibility, and flyer before choosing your next action.

Helpful details

  • Parking planAdd parking guidance if attendees need to know where to stage or avoid parking.
  • Ride-out planAdd the next spot, leave time, and notes if the group is driving afterward.
  • Pre-meetsUse pre-meets when people need a smaller meetup before the main meet.

After publishing

After publishing, open Host Tools to manage that meet.

Troubleshooting

  • Cannot publishCheck required fields such as title, time, location, and visibility.
  • End time is rejectedConfirm the end time is after the start time, or leave it empty.
  • Draft is missingCheck the same iPhone where you saved it.
  • Wrong host shownReview Host credit and the credited account or social link. Some official posts are attributed to Idle; contact support if the attribution looks wrong.
  • Details look wrong after postingOpen Host Tools and review the selected hosted meet.

Host responsibly

Hosts are responsible for following local laws, respecting venues, and setting expectations that keep the meet safe and organized.

Want your meet on Idle?

If you have a flyer, date, time, location, host name, and social link ready, use the meet submission page.
