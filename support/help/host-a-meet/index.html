Hosting

Host a meet

A good meet page gives people the basics before they leave: where, when, the full time window if there is one, who is hosting, how visible the meet is, and what to expect when they arrive.

Before you publish

  • TitleUse a clear name that matches the meet.
  • Date and timeMake sure the start time is correct before sharing.
  • Optional end timeAdd an end time only when the meet has a clear start-to-end window.
  • LocationAdd the location name and city so attendees can understand where they are going.
  • RulesAdd expected rules like no revving, no burnouts, and respect the location.
  • VisibilityChoose public if nearby people can discover it, or group if it should stay inside a group.

Helpful details

  • FlyerCreate a clean flyer or import an existing flyer and review the details before publishing.
  • Parking planAdd parking guidance if attendees need to know where to stage or avoid parking.
  • Ride-out planAdd the next spot, leave time, and notes if the group is driving after the meet.
  • Pre-meetsUse pre-meets when people need a smaller meetup before the main meet.
  • Host creditCredit another host when posting on their behalf, while keeping management permissions clear.

After publishing

Use Host Tools to manage the meet, send quick updates, adjust flyer or parking details, cancel if needed, review past context, or use Host again later.

Drafts

If you start hosting a meet and leave before publishing, Idle may let you continue the saved draft on the same device. Drafts are local to that app session, so do not rely on them as a shared or synced copy.

Troubleshooting

  • Cannot publishCheck required fields like title, time, location, and visibility.
  • End time is rejectedConfirm the end time is after the start time, or leave the end time empty.
  • Draft is missingDraft recovery depends on the same device and app session.
  • Wrong host shownReview Host credit and confirm the credited account or social link is correct.
  • Details look wrong after postingOpen Host Tools and update the selected hosted meet.

Host responsibly

Hosts are responsible for following local laws, respecting venues, and setting expectations that keep the meet safe and organized.

Want your meet on Idle?

If you have a flyer, date, time, location, host name, and social link ready, use the meet submission page.
